# Placoro_support.io
プラコロ HP・エネコロ・ワザ管理ツール

## 1. メイン画面
- ポケモン情報表示：セッティングで選択中のポケモン名と弱点属性を表示。
- HP（体力）管理：初期値120（0〜120の範囲で△+10 / ▽-10ボタンで増減）。
- エネコロ管理：初期値3コ（△+1 / ▽-1ボタンで増減、最小0）。
- 使うワザ枠：下部の4つのワザカードをタップすると、一番上の大きな枠へ選んだワザ（名前・必要エネ・威力・追加効果）が移動・表示されます。
- リセットボタン：HPを120、エネコロ数を3コへ一括リセット。
- セッティング画面切替ボタン：設定画面へ遷移。

## 2. セッティング画面
- 使用ポケモン選択：プルダウンでポケモンを変更可能（ピカチュウ、リザードン、カメックス、フシギダネ、ミュウツーなどを登録済み）。
- 使用ワザ選択：選択したポケモンが持つワザリストから、最大4つまで選択して組み合わせを作成可能。
- メイン画面へ反映：選択した内容を維持したままメイン画面へ復帰。

## 3. スマホのトップ画面に出す方法
Safari画面下部の 共有アイコン（四角に上矢印） をタップします。\
メニューから 「ホーム画面に追加」 を選択すると、スタンドアロンアプリとしてiPhone上で動作します。
アップデートによってアプリ内容の変更があった場合、再度同様の手順が必要です。
